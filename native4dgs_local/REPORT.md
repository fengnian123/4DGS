# Native 4DGS 实测结果与复现范围

三组实验在 2026 年 11 月 5 日前完成完整预算和评测。实现来自固定版本官方代码，并包含已核对的梯度、透明度加载、兼容性和续训修正。以下是这次复现的结果，不宣称与作者原始实验逐位一致。

## 训练覆盖

|---|---:|---:|---:|---:|---:|

Coffee 从训练相机第 0 帧产生的 589,372 个稠密 COLMAP 点中初始化，保留全部 18 个相机、每相机 300 帧；17 个训练相机共 5,100 帧，留出一个测试相机共 300 帧。没有将视频降采样到早期试跑的 50 帧，也没有设置高斯数量上限。

所有终点均启用空间三阶和时间二阶颜色基。Jumping Jacks 最佳的 4,000 步检查点启用空间三阶、时间一阶颜色基；不能将它标成“时间二阶终点模型”。这一场景仍有后期质量下降，完整预算并不保证测试指标单调上升。此报告不把下降解释为已解决的问题。

本次仅覆盖两个数据集家族和三个场景，没有完整基准平均数、消融矩阵或严格渲染速度基准。仓库原有 Wu 4DGaussians Coffee 使用 676×507 和不同训练检查点，与这里的结果不能直接据此判定方法优劣。

## 相对官方发布代码的修改

固定源码提交为 `121e360ce23d6e9ca7734072393414c844dfaea2`。提交包只包含一个完整补丁；恢复后的 766 个源文件与服务器训练快照逐字节相同。详细文件哈希见 `provenance/source_manifest.json`，十个修改文件见 `provenance/source_changes.json`。

- **CUDA 颜色梯度**：修正一阶空间球谐的梯度基项、时间余弦导数符号，以及第二时间频率梯度应累加却覆盖的问题。实际 CUDA 有限差分检查由 111/116 通过变为 116/116 通过。这是本次核查结果，不表述为作者已确认的问题。
- **透明度加载**：修正 D-NeRF 透明通道被重复相乘的问题，保持透明背景合成的一致性。80 个样本检查与目标合成逐像素一致；Coffee RGB 数据不经过这一透明通道路径。
- **工具链与相机**：补齐 CUDA 所需头文件、使用 Pillow 需要的无符号像素类型、由内参恢复有效视场角、限制图像加载线程；显式加载本实验自己的旧格式检查点。修正 SSIM 日志值。
- **内存与续训**：保留 Gaussian Adam 状态和冻结后的环境图；在反向传播与增密期间将 Adam 状态暂存 CPU，在原 GPU Adam 更新之前搬回。没有降低分辨率、批大小或训练预算。数值检查包含更新、拼接、剪枝和重置，其中 108 个增密相关比较逐位一致。

完整证据在 `provenance/validation/`。这些检查覆盖被测路径，不等于对所有输入和实现分支的形式化证明。

## Coffee 的续训记录

修正版 Coffee 从头训练，在约 5,000 步和 11,600 步遇到显存不足。先从 5,000 步恢复，后从 11,500 步检查点恢复，最终训练到 30,000 步。两次恢复均保留 Gaussian 参数及 Adam 状态，环境图已到冻结阶段；本轮没有重置早期背景优化器后冒充连续训练。

官方格式不保存随机数和数据加载器位置，因此恢复后采样顺序重新开始。CPU 暂存和未释放图引用的处理用于降低峰值显存；其代价是额外传输时间。记录中的 GPU 渲染/反向计时不能代替完整训练每步时间。

## 图片与视频怎么读

对比图三列是“真实图 / 重建 / 误差×5”。最佳和终点各一张，避免只展示好看的检查点。两类视频只展示最佳模型的重建：一个固定相机播放时间，一个固定时间转相机。Coffee 漫游范围较小；训练相机覆盖之外的视角可能有空洞、漂浮点和模糊，不是可验证的真实场景补全。

原生查看器和统一查看器适配器已用三个场景的最佳与终点共六个模型检查：都能加载、改变时间并改变视角。此次检查使用已有模型，没有重新训练；打包后的全新环境安装和长时间重训未重复执行。

## 代码组织的变化

训练核心补丁保持服务器实际版本不变。外围脚本在整理时仅做可迁移改造：用环境变量指定实验目录，统一数据和结果路径，添加命令行入口，将个人 SSH 桥接改为回环 HTTP 服务。历史一次性进程迁移、自动删除和登录修复脚本未纳入可运行流程。

新增统一查看器适配器通过现有的相机矩阵、视场角、分辨率和时间参数渲染。无需用预录视频冒充自由视角。三组结果的训练数字和媒体文件保留原始输出，仅对指标 JSON 的路径和浏览所需顶层字段做整理。
